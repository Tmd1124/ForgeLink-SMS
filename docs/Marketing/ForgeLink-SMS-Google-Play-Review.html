01

Core functionality

ForgeLink SMS is a complete replacement for the phone's built-in messaging app. Its only purpose is sending, receiving, reading and organizing the user's own SMS and MMS messages, and it must be the default SMS handler to work.

  • Send and receive SMS and MMS: text, photos, video, audio, contact cards and real group conversations.
  • Organize the inbox: a Chats lane for people, an Updates lane that groups automated business texts by topic, and a Screener that holds texts from unknown numbers without notifications until the user allows them.
  • Messaging tools: reactions, reply-with-quote, voice messages, quick replies, scheduled messages (including to groups), forwarding, drafts, and replying or marking as read from the notification.
  • Personal organization: favorites, color filters with emoji names, a bubble-based home screen, mute, snooze, archive, block, and Trash with 30-day recovery.
  • Search across all conversations and within a conversation, plus a Photos & links view per conversation.
02

SMS & Call Log permission policy

ForgeLink qualifies under the Default SMS handler core use case. It requests no Call Log permissions.

  • Default handler first. On first launch, the setup screen asks the user to make ForgeLink the default SMS app through Android's RoleManager (ROLE_SMS). The "Grant permissions" step stays disabled until the role is granted, so SMS permissions are never requested before ForgeLink is the default handler.
  • Handles every default-SMS entry point: SMS_DELIVER (protected by BROADCAST_SMS), WAP_PUSH_DELIVER for MMS (protected by BROADCAST_WAP_PUSH), a RESPOND_VIA_MESSAGE service (protected by SEND_RESPOND_VIA_MESSAGE), and a SENDTO compose activity for sms:, smsto:, mms: and mmsto: links.
  • Losing the role is handled. If the user switches to another default SMS app, ForgeLink returns to its setup screen on next launch instead of using SMS permissions.
  • No access to data beyond messaging. SMS data is used only to show, send, search and organize the user's messages on the device. It is never uploaded, sold or shared.

04

Data safety

ForgeLink does not collect or share user data as Google Play defines it. The developer operates no servers and includes no analytics, crash-reporting, advertising or attribution SDKs.

Stays on the device

  • Messages, in Android's standard message storage
  • Contacts (read only, never copied)
  • App settings: drafts, filters, favorites, mutes, schedules, quick replies
  • Voice recordings and attachments the user sends

Leaves the device only when

  • The user sends a message (through their carrier, to their recipient)
  • A link preview is shown (the linked website receives a normal page request)
  • The user's own Android backup is enabled (managed by the user)

Technical requirements

  • Target API level 36 (Android 16), meeting the requirement for new apps from August 31, 2026. Minimum API 24 (Android 7.0).
  • Android App Bundle signed with a dedicated upload key; the developer opts in to Play App Signing.
  • 64-bit native code only (arm64-v8a, x86_64).
  • Edge-to-edge and predictive back supported: content respects system bars, and the back gesture and button navigate within the app.
  • Battery-friendly scheduling: scheduled sends and snoozes use setAndAllowWhileIdle, so no exact-alarm permission is required.
  • No foreground services, no background location, no accessibility service, no device admin.
  • Notification permission (POST_NOTIFICATIONS) requested at runtime on Android 13+.

08

How to review ForgeLink

No login or special access is needed. A device with a SIM (or an emulator with SMS support) shows every feature.

  1. Install and open ForgeLink SMS. The setup screen appears.
  2. Tap 1. Make this my default SMS app and accept Android's prompt.
  3. Tap 2. Grant permissions (enabled only now) and allow SMS, Contacts, Phone and Notifications, then Continue.
  4. The Chats screen shows conversations; Updates and Screener tabs hold business texts and unknown senders.
  5. Open a conversation, send a text, and receive one. Long-press a message to react, reply, copy or forward.
  6. Explore Menu → Settings → Display to change the home-screen layout, and Menu → Filters to create a color filter.
